# pyth-hermes

Python client for the Pyth Network Hermes API (real-time price oracle). Sync + async, SSE streaming, Pydantic v2.

## Install

```bash
pip install pyth-hermes
```

The distribution is `pyth-hermes`; the import package is `pyth_hermes`.

## Quick start

```python
import pyth_hermes
```

See the [API reference](api.md) for the full surface.
